# Empty-workspace landing and Seek: implementation plan

> Execute task by task with superpowers:executing-plans, committing after each task.

**Goal:** Replace the "Panoptic / Import from SSMS / New environment" empty state with the "C - Quiet wordmark" landing: a Seek box over environments, connections and recent objects, a short action list, an engine status line and a faded wordmark. Add an unconnected "Query N" tab whose connection picker is the same Seek.

**Architecture:** All behaviour lives in pure, unit-tested TypeScript modules: `seek.ts` (index, ranking, keys), `usage.ts` (last used and recent objects, in local storage), `shortcuts.ts`, the tree model's `focus`, and the query store's unconnected tabs. Svelte components (`SeekBox`, `Landing`, the picker in `QueryView`) only render and forward events. Seek is built here as its own module so a later Ctrl+P palette reuses it unchanged.

**Tech stack:** Svelte 5 (runes), TypeScript, vitest, Monaco (language switch on connect), Tauri (`sidecar_start` for Restart), headless Chrome for screenshots, `scripts/bench.ps1` for timing.

**Decisions (from the user, 2026-10-31):**
- The landing shows when no tab is open **and nothing is selected**. It replaces only DetailPane's empty block; a selected node still shows its details. Esc in the tree clears the selection and brings the landing back.
- "Reopen last session" and "Pick up where you left off" restore the **last place only** (env, host, object), from a usage record in local storage: select it in the tree and open a new query tab there. No tab or text restore.
- The unconnected "Query N" tab shows the **editor and the picker**; Run is disabled and IntelliSense is off until connected; the editor's language is set on connect.
- Screenshots come from a **dev-only preview page** with synthetic data (not in the build), captured with headless Chrome.
- Branch `feature/landing`. Colours go in `src/app/app.css`. `--accent` (blue) is untouched; the landing uses `--brand-cyan` and `--brand-amber`, whose values change to the icon's `#24c8db` and `#ffc131`. New: `--wordmark-faded`, `--kbd-bg`, `--kbd-border`, `--landing-bg`. No hex in components.
- Shortcuts: Ctrl+N stays New query (with a node selected it targets the node, as today; with none it opens an unconnected tab), Ctrl+Shift+N New environment, Ctrl+I Import, Ctrl+P focuses Seek.

**Branch name:** `feature/landing`. The user's own rule requires a `feature/`, `fix/` or `chore/` prefix; the older `feat/*` branches predate it.

**Interpretations (agreed by the user, 2026-10-31; restate them in the PR description):**
- "Nine rows max" counts selectable rows. The muted "N more, type to find" line is a hint, not a row. (1 resume + 5 envs + 3 recent = 9.)
- A "recent object" is any node a query tab was opened on below connection level (a database, table, view, procedure or container), newest first, 20 kept.
- "opened in NNN ms" is launch to engine ready (`mainToSidecarReadyMs`), the moment the landing becomes usable.
- "Do not use the word sidecar anywhere user-facing": the status bar texts change too (Task 9), not only the landing.
- Light theme: the new variables get light values derived from existing tokens, so the landing is readable there. The spec's exact hexes are the dark values.

```ts
// Where the user has been: per-environment last use and use count, the last place a query tab was opened, and the
// recent objects (docs/landing.md, "Usage"). Local storage only: a convenience on this machine, never sent anywhere.

export interface Place {
  envId: string;
  /** The connection's node id and display name. */
  hostId: string;
  hostName: string;
  /** The node the tab was opened on: the connection itself, a database or an object. */
  nodeId: string;
  label: string;
  kind: string;
}

export interface Usage {
  envs: Record<string, { last: number; uses: number }>;
  last?: Place;
  /** Places below connection level, newest first. */
  recent: Place[];
}

export const EMPTY_USAGE: Usage = { envs: {}, recent: [] };
export const RECENT_KEEP = 20;
const KEY = "panoptic.usage";

type Storage = Pick<globalThis.Storage, "getItem" | "setItem">;

export function recordUse(usage: Usage, place: Place, now: number): Usage {
  const env = usage.envs[place.envId];
  const recent = place.kind === "connection" ? usage.recent : [place, ...usage.recent.filter((r) => r.nodeId !== place.nodeId)].slice(0, RECENT_KEEP);
  return { envs: { ...usage.envs, [place.envId]: { last: now, uses: (env?.uses ?? 0) + 1 } }, last: place, recent };
}

export function loadUsage(storage: Storage | undefined = globalThis.localStorage): Usage {
  try {
    const raw = storage?.getItem(KEY);
    const parsed = raw ? (JSON.parse(raw) as Usage) : undefined;
    return parsed && typeof parsed.envs === "object" && Array.isArray(parsed.recent) ? parsed : EMPTY_USAGE;
  } catch {
    return EMPTY_USAGE;
  }
}

export function saveUsage(usage: Usage, storage: Storage | undefined = globalThis.localStorage): void {
  try {
    storage?.setItem(KEY, JSON.stringify(usage));
  } catch {
    // Private mode or full storage: the landing just has less to offer next time.
  }
}
```

**Step 3: implementation**
```ts
// Seek (docs/landing.md, "Seek"): one index over environments, their connections and recent objects, ranked for a
// query. Pure, so the landing box, the query tab's connection picker and a later Ctrl+P palette all share it.

import type { Place, Usage } from "./usage";

export interface SeekHost {
  /** The connection's node id. */
  id: string;
  name: string;
  envId: string;
}

export interface SeekEnv {
  /** The environment's node id. */
  id: string;
  name: string;
  hosts: SeekHost[];
}

export interface SeekIndex {
  envs: SeekEnv[];
  usage: Usage;
}

export type SeekRow =
  | { kind: "resume"; group: "resume"; place: Place }
  | { kind: "env"; group: "envs"; env: SeekEnv }
  /** A hint, not selectable: how many environments the cap hid. */
  | { kind: "more"; group: "envs"; count: number }
  | { kind: "host"; group: "hosts"; host: SeekHost; env: SeekEnv }
  | { kind: "recent"; group: "recent"; place: Place };

export const ENV_CAP = 5;
export const RECENT_CAP = 3;
/** Selectable rows; the "more" hint does not count. */
export const MAX_ROWS = 9;

export const selectable = (r: SeekRow) => r.kind !== "more";

/** 3 for a prefix of the text, 2 for the start of a word in it, 1 anywhere in it, 0 not in it. */
function score(text: string, token: string): number {
  const t = text.toLowerCase();
  const at = t.indexOf(token);
  if (at < 0) return 0;
  if (at === 0) return 3;
  return /[\s._\-/]/.test(t[at - 1]) ? 2 : 1;
}

const best = (texts: string[], token: string) => Math.max(0, ...texts.map((x) => score(x, token)));

function cap(rows: SeekRow[]): SeekRow[] {
  const out: SeekRow[] = [];
  let count = 0;
  for (const r of rows) {
    if (selectable(r) && ++count > MAX_ROWS) break;
    out.push(r);
  }
  return out;
}

/** Environments by last use, then use count, then name. */
function byUse(usage: Usage) {
  return (a: SeekEnv, b: SeekEnv) =>
    (usage.envs[b.id]?.last ?? 0) - (usage.envs[a.id]?.last ?? 0) ||
    (usage.envs[b.id]?.uses ?? 0) - (usage.envs[a.id]?.uses ?? 0) ||
    a.name.localeCompare(b.name);
}

export function seek(index: SeekIndex, query: string, scope: "all" | "connections" = "all"): SeekRow[] {
  const tokens = query.toLowerCase().split(/\s+/).filter(Boolean);
  // Usage outlives config: a place in an environment that has since been removed is dropped, never offered.
  const known = new Set(index.envs.map((e) => e.id));
  const usage: Usage = {
    ...index.usage,
    last: index.usage.last && known.has(index.usage.last.envId) ? index.usage.last : undefined,
    recent: index.usage.recent.filter((r) => known.has(r.envId)),
  };
  const ordered = [...index.envs].sort(byUse(usage));
  const recentIn = (env: SeekEnv) => usage.recent.filter((r) => r.envId === env.id);

  if (scope === "connections") {
    const hosts = ordered.flatMap((env) => env.hosts.map((host) => ({ host, env })));
    const ranked = tokens.length
      ? hosts
          .map((h) => ({ ...h, s: tokens.every((t) => best([h.host.name, h.env.name], t) > 0) ? tokens.reduce((sum, t) => sum + 2 * score(h.host.name, t) + score(h.env.name, t), 0) : 0 }))
          .filter((h) => h.s > 0)
          .sort((a, b) => b.s - a.s)
      : [...hosts].sort((a, b) => Number(b.host.id === usage.last?.hostId) - Number(a.host.id === usage.last?.hostId));
    return cap(ranked.map(({ host, env }) => ({ kind: "host", group: "hosts", host, env })));
  }

  if (tokens.length === 0) {
    const rows: SeekRow[] = [];
    if (usage.last) rows.push({ kind: "resume", group: "resume", place: usage.last });
    for (const env of ordered.slice(0, ENV_CAP)) rows.push({ kind: "env", group: "envs", env });
    if (ordered.length > ENV_CAP) rows.push({ kind: "more", group: "envs", count: ordered.length - ENV_CAP });
    for (const place of usage.recent.filter((r) => r.nodeId !== usage.last?.nodeId).slice(0, RECENT_CAP)) rows.push({ kind: "recent", group: "recent", place });
    return index.envs.length ? cap(rows) : [];
  }

  // An environment matches when every token is in its name or id, a host's name, or a recent object's label in it.
  const matched = ordered
    .map((env) => {
      const texts = [env.name, env.id, ...env.hosts.map((h) => h.name), ...recentIn(env).map((r) => r.label)];
      const all = tokens.every((t) => best(texts, t) > 0);
      return { env, s: all ? tokens.reduce((sum, t) => sum + 4 * score(env.name, t) + 1, 0) : 0 };
    })
    .filter((m) => m.s > 0)
    .sort((a, b) => b.s - a.s);
  if (matched.length === 0) return [];

  const rows: SeekRow[] = matched.slice(0, ENV_CAP).map(({ env }) => ({ kind: "env", group: "envs", env }));
  if (matched.length > ENV_CAP) rows.push({ kind: "more", group: "envs", count: matched.length - ENV_CAP });
  const top = matched[0].env;
  const inTop = (texts: string[]) => tokens.every((t) => best([...texts, top.name, top.id], t) > 0);
  for (const host of top.hosts.filter((h) => inTop([h.name])).sort((a, b) => a.name.localeCompare(b.name)))
    rows.push({ kind: "host", group: "hosts", host, env: top });
  for (const place of recentIn(top).filter((r) => inTop([r.label, r.hostName])).slice(0, RECENT_CAP)) rows.push({ kind: "recent", group: "recent", place });
  return cap(rows);
}
```

**Step 3: implementation** (append to `seek.ts`):
```ts
export type SeekKey =
  | { kind: "move"; index: number }
  /** Enter: scope the tree to the row (or reopen a place). */
  | { kind: "open"; row: SeekRow }
  /** Ctrl+Enter: a new query tab on the row's connection. */
  | { kind: "query"; row: SeekRow }
  | { kind: "clear" }
  | { kind: "leave" };

/** What a key in the Seek box does; undefined leaves the key to the browser. active indexes the selectable rows. */
export function seekKey(e: { key: string; ctrlKey: boolean; shiftKey: boolean }, rows: SeekRow[], active: number, query: string): SeekKey | undefined {
  const list = rows.filter(selectable);
  switch (e.key) {
    case "ArrowDown":
      return list.length ? { kind: "move", index: Math.min(active + 1, list.length - 1) } : undefined;
    case "ArrowUp":
      return list.length ? { kind: "move", index: Math.max(active - 1, 0) } : undefined;
    case "Enter":
      return list[active] ? { kind: e.ctrlKey ? "query" : "open", row: list[active] } : undefined;
    case "Tab": {
      if (e.shiftKey || !list[active]) return undefined;
      const next = list.findIndex((r, i) => i > active && r.group !== list[active].group);
      return next >= 0 ? { kind: "move", index: next } : undefined;
    }
    case "Escape":
      return query ? { kind: "clear" } : { kind: "leave" };
  }
  return undefined;
}
```

**Step 3: implementation**
```ts
// App-wide shortcuts shown on the landing (docs/landing.md, "Keys"). Ctrl+N with a tree node selected is the node's
// New query (node-menu.ts) and is checked first; this is what the keys do otherwise.

export type GlobalAction = "newQuery" | "newEnvironment" | "import" | "seek";

export function globalShortcut(e: { key: string; ctrlKey: boolean; metaKey: boolean; shiftKey: boolean }, inEditor: boolean): GlobalAction | undefined {
  if (!(e.ctrlKey || e.metaKey)) return undefined;
  switch (e.key.toLowerCase()) {
    case "n":
      return e.shiftKey ? "newEnvironment" : "newQuery";
    case "i":
      // Monaco uses Ctrl+I to open suggestions.
      return inEditor ? undefined : "import";
    case "p":
      return "seek";
  }
  return undefined;
}
```

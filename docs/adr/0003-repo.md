# 0003. Public MIT repo on a personal account

- Status: Accepted
- Date: 2026-10-29

## Context

The tool is generic and doubles as a portfolio piece. Employer-specific integrations must not leak into it.

## Decision

afrugalpenguin/panoptic is public from the first commit under MIT. Employer-specific connectors live in a separate private repo as plugins.

## Consequences

No secrets, tenant names or connection details may ever be committed. CI runs on free public-repo Windows runners.

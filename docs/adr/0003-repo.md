# 0003. Public MIT repo on a personal account

- Status: Accepted
- Recorded: 2026-10-29

## Context

The tool is generic and doubles as a portfolio piece. Personal data must never leak into it.

## Decision

afrugalpenguin/panoptic is public from the first commit under MIT. Personal data (server names, tenants, credentials, connection details) never touches this repository: test fixtures are synthetic and user configuration stays on the user's machine.

## Consequences

No secrets, tenant names or connection details may ever be committed. CI runs on free public-repo Windows runners.

# 0004. UI framework: Svelte 5 or plain TypeScript

- Status: Proposed
- Date: 2026-10-29

## Context

The tree and grid are the product and must hit 60 fps with 50k nodes and 100k rows. React and Angular are familiar but heavier.

## Decision

To be decided in M0 from benchmark numbers in docs/benchmarks.md, comparing a virtualised tree and grid in Svelte 5 and in plain TypeScript. Until then the scaffold uses plain TypeScript.

## Consequences

Pending the M0 benchmark.

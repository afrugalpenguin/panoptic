# 0007. Entra first, then SQL auth, then Cosmos keys

- Status: Accepted
- Date: 2026-10-29

## Context

This matches how the target Azure SQL and Cosmos resources are actually reached. Brokered sign-in (WAM) on an Intune-managed laptop is unproven.

## Decision

The sidecar authenticates with MSAL.NET using the WAM broker, falling back to device-code flow. SQL auth and Cosmos key auth are supported second and third. Tokens are cached per connection in the sidecar and never written to disk unencrypted.

## Consequences

The UI never holds tokens. Whether WAM works on the work laptop is recorded in M0.
